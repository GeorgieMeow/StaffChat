A Paper Minecraft plugin for 1.21.11 that lets your staff chat in a private chat in minecraft!

# Features:

- Private staff chat that normal players can't see!

- You can call other staff members to tell them to join the staff chat!

- very customizable, can change message format, change player feedback messages, (ex: toggle messages, no permission messages, etc) and more!

# Installation:
## Only tested on Paper 1.21.11!

- Download the latest .jar from the releases page, put the .jar into your plugins folder and restart the server!
